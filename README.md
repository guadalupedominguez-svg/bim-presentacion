# bim-presentacion

Animaciones HTML para la presentación "BIM en la construcción" (Visme).

- `planeacion/` — escalonamiento de palabras de planeación estratégica.
- `pregunta-bim/` — diapositiva 2: ¿BIM? ¿En construcción? ...Pero así sin BIM hemos cumplido.
- `diente-de-leon/` — diente de león: sus semillas forman Personas · Procesos · Tecnología y luego otra flor del lado contrario (tipografía Arimo).
- `frio-4d-loop/` — diapositiva 15: repite en loop la simulación 4D de Oficinas Frío Express (peasa-workspace).
- `perfil-obra/` — diapositiva 31: Perfil digital en obra, con la frase "Convierte información en decisiones".
